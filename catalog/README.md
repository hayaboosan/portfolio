# 賃貸物件検索UI（まどり不動産）

家賃・間取り・面積・駅徒歩・築年数・こだわり条件で **21件の賃貸物件をその場で絞り込める、データ駆動の検索UI** です。スクロール型のLPや1画面の見積もりアプリとは別ジャンルの「**一覧×絞り込み**」を、フレームワーク不使用の vanilla HTML / CSS / JavaScript で実装しています。

🔗 デモ: https://hayaboosan.github.io/portfolio/catalog/

> ※「まどり不動産」は架空の不動産会社です。物件・エリア・沿線・価格・設備はすべて説明用の例示で、実在の物件・事業者・実勢価格とは関係ありません。問い合わせ・申し込み・データ送信は行えません。

## できること

- **多軸の絞り込み（ファセット検索）** — フリーワード／家賃上限／間取り（複数選択）／専有面積／駅徒歩／築年数／エリア（駅・複数選択）／こだわり条件（複数選択）／お気に入りのみ
- **件数のリアルタイム更新** — 条件を変えるたびに該当件数が即時に更新
- **並べ替え** — おすすめ順／家賃が安い・高い順／面積が広い順／駅から近い順／築年数が浅い順／新着順
- **アクティブ条件のチップ表示** — 効いている条件をタグで可視化し、個別に「×」で解除、または「すべて解除」
- **URLに状態を保存** — 絞り込み・並べ替え・表示形式をURLに保存し、その状態をそのまま共有・ブックマーク可能
- **お気に入り保存** — ハートで保存（`localStorage`に永続化）し、「お気に入りのみ表示」で絞り込み
- **リスト／グリッド表示の切り替え**
- **0件時の空状態** と、ワンタップで条件をリセットする導線

## 設計のポイント

### プログレッシブエンハンスメント（段階的強化）
物件データの「正」は **静的HTML**（`<article class="bukken" data-*>`）です。JavaScript が無効でも全21件をそのまま一覧でき（SEO・スクリーンリーダーにも有利）、JS が有効なときだけ `data-*` を読んで絞り込み・並べ替え・状態保存を **上乗せ** します。JS無効時は機能しない絞り込みUIを隠し、案内文を表示します。

### 「派生条件」は実データから判定
「2階以上」は所在階（`data-floor`）から、「南向き」は方角（`data-dir`）から判定します。手付けのフラグに頼らないため、表示と絞り込みの食い違いが起きません。

### アクセシビリティ（WCAG 2.1 AA 配慮）
- カスタムチェックボックス／セレクトでもキーボード操作・`:focus-visible` のフォーカスリングを担保
- 件数変更を `role="status"` のライブリージョンで読み上げ通知
- モバイルの絞り込みドロワーは `role="dialog"` / `aria-modal`、**フォーカストラップ**・背景の `inert` 化・Esc で閉じる・フォーカス復帰に対応
- フィールドセット／凡例、ラベルとコントロールの関連付け、見出し階層、`prefers-reduced-motion` への配慮
- 文字色は本文で 4.5:1 以上、フォーム枠・大きな文字は 3:1 以上のコントラストを確保

### 横スクロールの防止
`html { overflow-x: clip; }` と各グリッド/フレックス子の `min-width: 0`、狭い画面でのカード縦積みで、320px 幅でも横スクロールが出ないことを確認しています。

## ディレクトリ構成

```
catalog/
├─ index.html        # 静的な物件一覧（21件）＋絞り込みUIのマークアップ
├─ css/
│  └─ style.css      # クール×グリーンの業務プロダクトUI配色・2ペイン/ドロワー
├─ js/
│  └─ main.js        # DOM由来の絞り込み・並べ替え・URL状態・お気に入り・ドロワー
└─ README.md
```

ビルド工程はありません。`index.html` を開くだけで動作し、静的ホスティングにそのまま載せられます。物件データは制作時に小さな生成スクリプトで静的HTMLへ書き出していますが、配信物には生成器を含めていません（手で `<article>` を編集しても同じように動きます）。

## 技術

`HTML5` / `CSS Grid` / `Flexbox` / `position: sticky` / カスタムプロパティ / `clamp()` / vanilla `JavaScript`（`URLSearchParams` によるURL状態管理・`localStorage`・`IntersectionObserver` 不使用の軽量実装）/ プログレッシブエンハンスメント / WCAG 2.1 AA 配慮
