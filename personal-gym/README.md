# 臨界 -RINKAI-｜パーソナルジム ランディングページ

「2ヶ月で、別人の自分へ。」をコンセプトにした、架空の完全予約制パーソナルジムのレスポンシブ LP です。
**結果にコミットする層**（短期集中で体を変えたい多忙な社会人・経営者）に向けた、ダーク × 電光ライムの**ハイエナジーな設計**を、フレームワーク不使用の手書き HTML / CSS / JavaScript で実装しています。

> ※ これはポートフォリオ用に制作した**架空のサンプル**です。掲載のブランド・住所・電話番号・料金・お客様の声・実績数値（ビフォーアフター）はすべてフィクションであり、特定の成果を保証するものではありません。

## 技術

- **HTML5**：セマンティックなマークアップ。`h1` は 1 つ、見出し階層を論理的に。
- **CSS（手書き / フレームワーク不使用）**
  - `:root` のカスタムプロパティで色・余白・角丸・モーションを一元管理
  - `clamp()` による流体タイポグラフィ（特大ヒーロー見出しまで滑らかに追従）
  - `grid` / `flexbox` によるカード主体のモダンレイアウト
  - モバイルファースト・レスポンシブ（320px 〜 1440px+、横スクロールなし）
  - BEM 風のクラス命名
- **JavaScript（バニラ / ライブラリ不使用）**
  1. ヘッダーのスクロール状態（透過 → 背景フェード）
  2. モバイルナビ開閉（背景クリック・Escape・リサイズで自動クローズ・ボディスクロールロック）
  3. FAQ アコーディオン（クリック + Enter / Space、`aria-expanded` 更新、高さアニメ）
  4. ページ内アンカーのスムーズスクロール（フォーカス移動付き）
  5. `IntersectionObserver` によるスクロール表示アニメ（グリッド内 stagger）
  6. 数字のカウントアップ（接頭辞 / 接尾辞・`easeOutCubic`・ビューポート進入時）
  7. 無料体験予約フォームの `e.preventDefault()` バリデーション → インライン成功メッセージ（**実送信なし**）
  8. モバイルスティッキー CTA（`#cta` フォーム・フッター表示中は退避し、送信ボタン／フッターとの重なりを回避）
  - スクロール処理は `requestAnimationFrame` で単一ハンドラに集約
- **フォント**：Google Fonts を `preconnect` + `display=swap` で読み込み
  - ディスプレイ見出し：Anton
  - 見出し補助 / ラベル：Oswald
  - 本文：Noto Sans JP
- **画像**：お客様の声のアバターは [randomuser.me](https://randomuser.me)、OGP は [picsum.photos](https://picsum.photos) の固定 seed URL（404 を出さない安定参照）+ `loading="lazy"`。ヒーロー背景・アイコン・装飾はインライン / 外部 SVG と CSS グラデーションで自作。

### アクセシビリティ
- 本文へのスキップリンク、`lang="ja"`
- 画像 `alt`、フォーム `label` 紐付け、`aria-describedby` でエラーメッセージを関連付け
- ナビ / アコーディオンに `aria-expanded`・`aria-controls`、FAQ パネルに `role="region"`
- `:focus-visible` の可視フォーカスリング、キーボード操作完結
- タップターゲット 44px 以上（ボタン・トリガー・スティッキー CTA）
- `prefers-reduced-motion` 対応（アニメ・パララックス・カウントアップを無効化し最終値を即表示）
- Windows ハイコントラスト（`forced-colors`）でも FAQ の開閉インジケータが視認可能
- **JS 無効でも完全に利用可能**（スクロール表示アニメ対象も含め全コンテンツが表示、FAQ は展開状態で表示、フォームはネイティブ検証、数字は HTML 内の最終値を静的表示）
  - スクロール表示アニメの非表示（`opacity:0`）とカウントアップの開始値リセットは `.js` クラス付与時のみ適用。JS が無効／失敗した場合は最終状態がそのまま見える設計

### コントラスト（WCAG AA）への配慮
ネオン系のライムは**コントラストが破綻しやすい**ため、使用箇所を限定しています。

- 電光ライム `#C8FF00` は**暗い面の上の文字 / 罫線 / 大きな数字**にのみ使用（チャコール `#0E0F11` 上で約 16:1、最も明るいカード面 `#1C1F23` 上でも約 14:1）
- ライムのボタン上の文字は**ニアブラック** `#0E0F11`（約 16:1）— ライムを明るい背景の小さな文字には使わない
- 本文は `#E7EAEC`（暗面上で約 14〜16:1）、補足テキストは `#AEB4B8`（最も明るいカード面 `#1C1F23` 上でも約 7.9:1）でいずれも AA を大きく上回る
- エラー文言は暗背景向けに `#FF6B6B`（約 6.5:1）、入力プレースホルダは `#7D8488`（約 4.7:1）で AA 以上

## ローカルでの開き方

外部依存（Google Fonts / randomuser.me / picsum.photos）の読み込みにインターネット接続が必要です。

### 方法 A：ファイルを直接開く（最も簡単）
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開きます。

### 方法 B：ローカルサーバーで開く（推奨）
一部ブラウザの挙動を実環境に近づけたい場合は、簡易サーバー経由が確実です。

```powershell
# このフォルダ（personal-gym）に移動してから実行
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

起動後、ブラウザで <http://localhost:8000> を開きます。

### 動作確認のポイント
- ブラウザ幅を 320px〜 まで狭め、横スクロールが出ないこと
- モバイル幅でハンバーガーメニューが開閉し、スティッキー CTA が表示されること
- 「選ばれる理由」「実績」の数字がスクロールでカウントアップすること
- FAQ がクリック / キーボード（Enter・Space）で開閉すること
- 予約フォームを空欄送信 → エラー表示、正しく入力 → 成功メッセージが出ること
- OS の「視差効果を減らす」設定でアニメーション・カウントアップが無効化されること
