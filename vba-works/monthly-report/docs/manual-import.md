# 手動インポート手順（build.ps1 が使えない場合）

`build.ps1` は Excel の「VBA プロジェクト オブジェクト モデルへのアクセス」（AccessVBOM）が
許可されている環境でのみ動作します。未許可の環境では **設定を勝手に変更せず**、
以下の手動手順で同じブックを組み立ててください。

## 1. 空のマクロ有効ブックを用意する

1. Excel を起動し、空白のブックを新規作成
2. 「ファイル」→「名前を付けて保存」で、このフォルダ（`monthly-report\`）に
   **Excel マクロ有効ブック（*.xlsm）** として `monthly-report-demo.xlsm` を保存

## 2. VBA ソースをインポートする

1. `Alt + F11` で VBE（Visual Basic Editor）を開く
2. プロジェクトエクスプローラーで `VBAProject (monthly-report-demo.xlsm)` を右クリック
   →「ファイルのインポート」
3. `src\` フォルダ内の 7 ファイルを 1 つずつインポートする
   - `modConfig.bas` … 定数集約
   - `modUtil.bas` … 共通ユーティリティ
   - `modImport.bas` … CSV一括取込
   - `modAggregate.bas` … 月次集計
   - `modReport.bas` … レポート生成
   - `modExport.bas` … PNG書き出し（ポートフォリオ用・実運用では不要）
   - `modMain.bas` … エントリポイント

> 注: `src\*.bas` は UTF-8 で保存しています。日本語コメントが文字化けする場合は、
> 一度メモ帳等で開いて「ANSI（Shift_JIS）」で保存し直してからインポートしてください
> （`build.ps1` はこの変換を自動で行っています）。

## 3. 実行ボタンを作る（任意）

1. 先頭シートの名前を `操作パネル` に変更
2. 「挿入」→「図」→「図形」で角丸四角形を配置し、「月次レポート生成」などの文字を入れる
3. 図形を右クリック →「マクロの登録」→ `GenerateMonthlyReport` を選択

ボタンを作らない場合も、`Alt + F8` → `GenerateMonthlyReport` の実行で同じ動作になります。

## 4. 動作確認

1. `sample-data\csv\` に日次売上CSV（`sales_YYYYMMDD.csv`）があることを確認
2. ボタン（または `Alt + F8`）から `GenerateMonthlyReport` を実行
3. 「生データ」「取込ログ」「月次レポート」の 3 シートが生成され、
   処理時間がメッセージと操作パネルに表示されれば成功

## トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| 「CSVフォルダが見つかりません」 | ブックの保存場所直下に `sample-data\csv` が必要。無い場合はフォルダ選択ダイアログが開くので、CSVのあるフォルダを指定する |
| 取込行数が 0 件 | ファイル名が `sales_*.csv` のパターンに一致しているか確認 |
| マクロが実行できない | 「ファイル」→「オプション」→「トラストセンター」でマクロの実行を許可するか、ファイルのプロパティで「許可する」にチェック（Mark of the Web の解除） |
