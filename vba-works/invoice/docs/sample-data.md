# サンプルデータ設計 — 請求書作成.xlsm（架空）

> このデータ設計は**すべて見本用の架空のもの**です。登場する会社名・住所・
> 口座・金額は実在のものではなく、金額や件数は「見本・想定値」です。
> 実在の企業・団体とは一切関係ありません。

## シート構成（4枚）

| シート名 | 役割 |
|---|---|
| 受注一覧(2026) | 受注データの入力表。ボタン3個を配置 |
| 請求書テンプレ | 請求書のレイアウト。マクロが転記してPDF化する |
| 設定 | 請求書番号・PDF保存先・差し込み文言 |
| 処理済み | 発行済みの行の保管場所（受注一覧と同じ列構成） |

※納品文書見本の「変更内容書」のとおり、受注一覧シートは
「受注一覧」→「受注一覧(2026)」に**改名された後**の状態を再現しています。
（修正前コード `src\before\` はこの改名で実行時エラー9になります）

## 受注一覧(2026)・処理済み の列構成（A〜H固定）

| 列 | 項目 | 型 | 備考 |
|---|---|---|---|
| A | 受注日 | 日付 | Workbook_Open が当月分に絞り込むキー |
| B | 顧客名 | 文字列 | 空欄だと請求書を作成できない（チェック対象） |
| C | 住所 | 文字列 | 請求書の宛先に転記 |
| D | 品目 | 文字列 | 明細1行（このブックは1受注＝1明細の運用） |
| E | 数量 | 数値 | 空欄なら1件扱い |
| F | 金額（税抜） | 数値 | 空欄だと請求書を作成できない（チェック対象） |
| G | 発行日 | 日付 | マクロが記入。空欄＝未発行（重複防止のキー） |
| H | 請求書No | 数値 | マクロが記入 |

**列の挿入・削除は不可**（マクロが列位置の定数で転記しているため）。

## サンプル行の構成（build.ps1 が生成。日付はビルド日基準で自動計算）

| 区分 | 行数 | 内容 |
|---|---|---|
| 前月・発行済み | 2行 | 請求書No 1020〜1021。発行日入り |
| 当月・発行済み | 2行 | 請求書No 1022〜1023。「まとめて作成」でスキップされる見本 |
| 当月・未発行 | 4行 | マクロ実行のデモ対象（No 1024〜1027 が採番される） |
| 当月・金額未確定 | 1行 | 金額が空欄の行。入力チェックで弾かれる見本 |
| 処理済みシート | 1行 | 前々月発行の請求書No 1019。「発行済みの行を整理」の結果の見本 |

## 設定シート

| セル | 内容 | 初期値 |
|---|---|---|
| B2 | 次の請求書番号 | 1024 |
| B3 | PDFの保存先フォルダ | `dist\請求書PDF`（build.ps1 が絶対パスを書き込む） |
| B4 | 差し込み文言（自社名・振込先） | みどり事務用品株式会社（架空）ほか |

## 請求書テンプレの転記先セル（マクロ FillTemplate が書き込む場所）

| セル | 内容 |
|---|---|
| G3 | 請求書番号（例 No. 1024） |
| G4 | 発行日 |
| B5 | 顧客名＋「御中」 |
| B6 | 住所 |
| D8 | ご請求金額（税込） |
| B11 / E11 / F11 / G11 | 品目／数量／単価／金額 |
| G13 / G14 / G15 | 小計／消費税（10%）／合計金額 |
| B18 | 差し込み文言（設定シートB4の内容） |

PDFファイル名：`請求書_番号4桁_顧客名.pdf`
保存先：設定シートB3のフォルダ＋年月フォルダ（例 `2026-07`）
