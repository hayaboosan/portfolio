# 請求書作成.xlsm（架空マクロ・見本）

ポートフォリオの納品文書見本
（[解読レポート](../../vba-docs/sample-report.html)・[変更内容書](../../vba-docs/sample-changelog.html)）が
題材にしている架空の Excel マクロ「請求書作成.xlsm」の**実物実装**です。

> **これは見本用の架空題材です。**
> このマクロ・データ・会社名・住所・金額はすべて見本用に自作した架空のもので、
> 実在の企業・実際のお客様のファイルとは一切関係ありません。
> 記載の件数・時間などの数値も「見本・想定値」です。

## 何ができるか

「受注一覧(2026)」シートの受注データから、顧客ごとの請求書を
「請求書テンプレ」シートで組み立てて **PDF として自動保存** するマクロです。

| ボタン（受注一覧シート上） | マクロ | 動き |
|---|---|---|
| 選択した行の請求書を作成 | `CreateInvoiceSelected` | 選択中の1件をPDF化し、発行日・請求書Noを記録 |
| 今月分をまとめて作成 | `CreateInvoicesMonthly` | 当月の未発行行すべてを順に処理 |
| 発行済みの行を整理 | `ArchiveIssuedRows` | 発行済み行を「処理済み」シートへ移動 |
| （ブックを開いたとき） | `Workbook_Open` | 受注一覧を当月分にフィルタ |

処理の詳細は納品文書見本「解読レポート」の記載と一致するように実装しています
（標準モジュール2本＋ブックモジュール1本・約420行・ボタン3個、
請求書番号は設定シートB2で採番、保存先は設定シートB3＋年月フォルダ、など）。

│   │   ├─ Module2.bas

│       ├─ Module2.bas

## 1コマンド再現手順

```powershell
pwsh -File build.ps1
```

これだけで次が自動で行われます（Windows ＋ デスクトップ版 Excel が必要）。

1. Excel COM でシート4枚＋架空サンプルデータ＋ボタン3個を組み立て
2. `src\after\` のVBAソースを注入して `dist\invoice-demo.xlsm` を保存
3. マクロを実際に実行し、`dist\請求書PDF\年月\` に請求書PDFを生成（時間計測つき）
4. `Range.CopyPicture`＋`Chart.Export` で `assets\` にスクリーンショットPNGを出力
5. `src\before\`（修正前版）を別ブックに注入して実行し、
   変更内容書見本と同じ「実行時エラー 9」が実際に起きることを確認

実行記録は `dist\build-summary.txt` に残ります。

> **セキュリティ設定について**：手順2のコード注入には Excel の
> 「VBAプロジェクト オブジェクト モデルへのアクセスを信頼する」が必要です。
> 無効な環境では build.ps1 は**設定を変更せず**、マクロ無しのシェルブックを
> 作成して `docs\manual-import.md`（手動インポート手順）に案内します。

生成された `dist\invoice-demo.xlsm` は「実行前」の状態で保存されるので、
開いてボタンを押せば同じデモを手動でも再現できます
（マクロ有効化の警告が出たら「コンテンツの有効化」を押してください）。

## before / after — 変更内容書見本との対応

`src\before\` と `src\after\` の差分（`docs\before-after.diff`）は、
納品文書見本「変更内容書」に書かれた修正そのものです。

| 変更内容書の記載 | 実装上の差分 |
|---|---|
| シート名「受注一覧」→「受注一覧(2026)」への変更で実行時エラー9 | before版はシート名 `"受注一覧"` を3か所に直書き |
| #1 `Module1` / `CreateInvoiceSelected` | `Worksheets("受注一覧")` → `Worksheets(SHEET_ORDERS)` |
| #2 `Module1` / `CreateInvoicesMonthly` | 同上 |
| #3 `ThisWorkbook` / `Workbook_Open` | 同上 |
| 定数 `SHEET_ORDERS` に集約 | `Module1` 先頭に `Public Const SHEET_ORDERS As String = "受注一覧(2026)"` を追加 |

build.ps1 の手順5で、before版が本当に「実行時エラー 9」で止まることを
自動確認しています（結果は `dist\build-summary.txt` 参照）。

## 実行時間（見本・想定値）

ビルド時の実測では、請求書4件のPDF作成・記録・採番が**約2.2秒**（1件あたり約0.55秒）でした。
手作業で「一覧から転記 → PDF化 → ファイル名を付けて保存 → 台帳に記録」を行うと
1件あたり5〜10分程度かかる想定なので、**月20件なら約2〜3時間分の作業が数十秒**になる計算です。
（手作業時間は一般的な想定値であり、実測値・実績値ではありません）
