# Atelier Lumen（アトリエ・ルーメン） — オンライン創造学校 LP

少人数制オンライン創造学校「Atelier Lumen」の架空サービスを題材にした、レスポンシブ・ランディングページのポートフォリオ作品です。
テーマは「夜の図書館／灯のともる工房」。深いネイビーを知性の象徴、温かみのある金を「灯＝気づき」の差し色とし、生成りの紙色を背景に敷くことで、静かで上質な知性とプレミアム感を表現しています。

> ※これはポートフォリオ用に制作した架空のサンプルです。実在の企業・サービスとは関係ありません。

---

## 概要

- **ブランド**: Atelier Lumen（アトリエ・ルーメン）
- **コンセプト**: 学びを、灯す。— 1クラス最大12名の少人数制／週次の個別添削／現役プロの伴走
- **想定ターゲット**: 25〜45歳の社会人。創造的スキルを体系的に学び直し、副業・転職・独立につなげたい知的好奇心の高い層

### セクション構成

1. ヘッダー／ナビ（ロゴ・アンカーリンク・モバイルはハンバーガー開閉）
2. ヒーロー／ファーストビュー（明朝大見出し＋金の光ラインSVG＋机のイラスト（自作SVG）の非対称2分割）
3. 選ばれる5つの理由（金の明朝大数字＋単線ラインアイコンの番号付きリスト）
4. 料金プラン（Light / Standard / Pro。中央のStandardを強調＋「いちばん人気」リボン）
5. 受講生の声（3カラム）
6. よくある質問（`<button>`＋`aria-expanded` によるJS制御アコーディオン）
7. 申込フォーム（氏名・メール・プラン・問い合わせ。クライアントバリデーション＋送信デモ）
8. フッター（ネイビー反転・架空サンプルの注記つき）

## 使用技術

- **HTML5**: セマンティックなマークアップ（`<header>` / `<main>` / `<section>` / `<article>` ほか）。`h1` は1つのみ、見出し階層を論理的に構成
- **CSS3**（フレームワーク不使用・全て手書き）
  - `:root` カスタムプロパティで色・余白・角丸・タイポを一元管理
  - `clamp()` による流体タイポグラフィ
  - CSS Grid / Flexbox によるモダンレイアウト（max-width 1120px）
  - モバイルファースト・レスポンシブ（320px〜1440px+、横スクロールなし）
  - 影を使わず1pxの罫線で区切るフラットで上品な設計、角丸2px（シャープ＝知的）
- **JavaScript**（バニラ・ライブラリ不使用）
  1. モバイルナビ開閉（`aria-expanded` 更新・Escapeで閉じる）
  2. FAQアコーディオン（クリック＋キーボード Enter/Space、`aria-expanded`/`aria-controls` 同期、排他開閉）
  3. ページ内アンカーのスムーズスクロール（フォーカス移動つき）
  4. IntersectionObserver によるスクロール表示アニメ（fade-up・stagger 80ms）
  5. 申込フォームのクライアントバリデーション → インラインの成功メッセージ（実送信なし）
  - ヘッダーのスクロール状態切替、画面上端の極細スクロール進捗バー、ヒーローの金の光ライン描画アニメ（`stroke-dashoffset`）
- **フォント**: Google Fonts を `display=swap` で読み込み
  - 見出し: Shippori Mincho B1（明朝）
  - 本文: Noto Sans JP（ゴシック）
- **アイコン**: すべてインラインSVGで自作（単線ラインアイコンをSVGスプライト化、ホバーで金に変化）
- **画像**: ヒーローの机のイラスト・受講生アバター（抽象シルエット）とも、すべて自作SVG（`assets/` 配下）。外部の写真サービスには依存しない。ヒーローには意味のある `alt`、アバターは氏名を本文に記載しているため空 `alt` を付与。万一画像が取得できない場合も、JS が壊れた画像アイコンを抑止し装飾的なプレースホルダ背景にフォールバックする

## アクセシビリティ

- 画像に適切な `alt`（情報を持つ画像は意味のある `alt`、氏名が本文にある装飾的なアバターは空 `alt`）
- フォーム項目は `<label for>` で紐付け、必須項目は `aria-required`、エラーは `role="alert"`
- ナビ・アコーディオンに `aria-expanded` / `aria-controls`
- `:focus-visible` のフォーカスリング、本文先頭へのスキップリンク
- 文字色と背景のコントラストは AA 基準を意識
- `prefers-reduced-motion` を尊重し、全アニメーションを無効化可能

## ローカルでの開き方

ビルド不要・依存パッケージなしです。

### もっとも簡単な方法

`index.html` をダブルクリックしてブラウザで開くだけで表示できます。

### ローカルサーバーで開く（推奨）

Google Fonts や IntersectionObserver の挙動を本番に近い形で確認したい場合は、簡易サーバー経由がおすすめです。

```bash
# このフォルダ（online-school）で実行

# Python がある場合
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く

# Node.js がある場合
npx serve .
```

> インターネット接続がある状態でご覧ください（Webフォントを外部から読み込みます）。
