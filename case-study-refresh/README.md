# サイト改修 ビフォーアフター事例 ― わかば整骨院（架空）

古い実装のままになっている店舗・クリニックのWebサイトを、**スマホ対応・読みやすさ・アクセシビリティ・集客導線**の観点からまるごと作り直すと、どこまで変わるのか。本事例では、架空の整骨院「わかば整骨院」を題材に、**2008年当時の作りのサイト（Before）** を、**現在の標準にあわせた新しいサイト（After）** へ改修した過程をまとめています。デザインの好みではなく、「なぜその変更が来院・問い合わせにつながるのか」を一つひとつ言語化することを重視しました。

> ⚠️ **架空サンプルについて**
> 院名・院長名・住所・電話番号・料金・お客様の声などはすべて**架空のサンプル**です。実在の整骨院・人物・団体とは一切関係ありません。地図・院内写真・ヒーロー画像もSVGで作成したプレースホルダーです。

## 改修前の問題点（カテゴリ別）

改修前のサイトには、**「集客の入口を細くしている要因」** が複数埋め込まれていました。それぞれ「何が問題か → なぜ集客・信頼の損失になるか」で整理します。

### 1. レスポンシブ非対応 / モバイル
- **問題:** `<meta viewport>` が無く、`width="820"` の固定幅テーブルを `<center>` で中央寄せ。
- **損失:** 来院検討者の多くはスマホ閲覧。診療時間・電話番号・アクセスが指で拡大しないと読めず、面倒になった見込み客が離脱。検索流入で最も多いモバイルユーザーを取りこぼしています。

### 2. レイアウト手法 / 保守性
- **問題:** ページ全体が入れ子の `<table>` と `spacer.gif` による段組み。Grid も Flex も不使用。
- **損失:** 文言1行の修正でもレイアウトが崩れやすく、院長自身では直せない。毎回業者依頼が必要で、結果として情報が何年も古いまま放置されます。

### 3. 可読性 / タイポグラフィ
- **問題:** `font-size:12px` / `line-height:1.3` と極端に小さく行間も詰まる。`ＭＳ Ｐゴシック` 固定。
- **損失:** 整骨院の主要客層である中高年・高齢者に文字が小さすぎて読みづらい。施術内容や料金が頭に入る前に疲れて離脱します。

### 4. アクセシビリティ / コントラスト
- **問題:** 注意書きが淡背景に `#999999`、フッターは濃緑背景に飽和グリーン `#3e8e41` のリンクで文字が背景に溶ける。
- **損失:** 休診日・保険適用の但し書きが見落とされ、来院後の「思っていたのと違う」トラブルや問い合わせ電話の増加につながります。視覚に不安のある方への不親切さは信頼も損ないます。

### 5. デザインの古さ / 第一印象
- **問題:** `<marquee>` で流れるお知らせ、`<blink>` の NEW!、偽アクセスカウンター、`Since 2008`、ベベルボタンなど 2008 年当時の演出。
- **損失:** 開いた瞬間に「何年も更新が止まっている院」という印象を与え、衛生面・施術の最新性まで疑われます。きれいな競合サイトと比較され、第一印象で選択肢から外されます。

### 6. 非推奨HTML / セマンティクス
- **問題:** `<font>`・`align`・`<center>`・`bgcolor` を多用。画像に `alt` なし。`header/nav/main/footer` ゼロ。`<html>` に `lang` 指定なし。
- **損失:** 画像が出ない時や読み上げ環境で内容が伝わらず、地図・院内写真が無意味に。検索エンジンも構造を理解できず、「近くの整骨院」検索で上位に出にくくなります。

### 7. 電話導線 / 操作性
- **問題:** 最重要の電話番号がすべてプレーンテキストで `tel:` リンクになっておらず、スマホでタップ発信できない。タップ領域も小さくフォーカススタイルもなし。
- **損失:** スマホ来院客が番号を手入力する手間を強いられ、面倒さからそのまま離脱。予約の最終ステップでの取りこぼしが直接的な売上機会の損失になります。

### 8. head / SEO・SNS
- **問題:** `meta description`・OGP・Twitterカードが皆無。`<title>` が「わかば整骨院ホームページ」と弱い。`head` に `alert` を出す簡易スクリプト直書き。
- **損失:** SNSやLINEでURLを共有してもリッチなプレビューが出ず、シェアされにくい。検索結果でも魅力的な説明文が出ずクリック率が低下し、集患の入口が細くなります。

## 改修内容（Before → After 対応表）

| 課題 | 改修（After で行ったこと） | 効果 |
|------|---------------------------|------|
| スマホで横スクロール必須 | `<meta viewport>` 追加＋モバイルファースト設計。固定820px幅を撤廃 | 幅320pxでも横スクロールなし。スマホでそのまま読める |
| テーブル＋spacer.gifの段組み | CSS Grid / Flexbox によるレイアウトへ全面置換 | 文言追加でも崩れにくく、更新コストが下がる |
| 12px・行間1.3の小さな文字 | `clamp()` で本文16〜17px・行間1.85に。丸ゴシック系Webフォント | 中高年でも疲れず読める。情報が頭に入る |
| 溶けて読めない配色 | 全テキストを WCAG AA 以上のコントラストで再設計 | 休診日・保険の但し書きが確実に伝わる |
| marquee/blink/偽カウンター | 静的な「お知らせ」リスト＋落ち着いたティール基調へ刷新 | 「きちんと運営されている院」という第一印象 |
| `<font>`・`align`・alt無し画像 | セマンティックHTML5＋全画像に説明的`alt` | 読み上げ・SEO・画像非表示時にも内容が伝わる |
| タップ発信できない電話番号 | すべて `tel:` リンク化。タップ領域44px以上 | スマホからワンタップで発信。離脱を防ぐ |
| 弱いtitle・OGP無し | 検索意図を含むtitle＋description＋OGP/Twitterカード | 検索・SNSでクリックされやすくなる |
| 電話のみの問い合わせ | アクセシブルな予約・問い合わせフォームを新設 | 営業時間外でも24時間受付でき、取りこぼしを減らす |

## 技術的な変更点

- **レイアウト:** ネストした `<table>` / `spacer.gif` / `<center>` を全廃し、**CSS Grid・Flexbox** で再構築。診療時間だけは意味的に正しい `<table>`（`<caption>`・`<thead>`・`scope`付き）として残し、狭い画面では表だけが横スクロールしてページ本体は崩れない設計に。
- **レスポンシブ:** `<meta viewport>` を追加し、**モバイルファースト**で記述。幅320pxで横スクロールが出ないことを確認済み。`min-width` ブレークポイントで段階的に多カラム化。
- **タイポグラフィ:** `font-size` を `clamp()` で可変化（本文16〜17px／行間1.85）。環境依存の `ＭＳ Ｐゴシック` をやめ、Google Fonts（`preconnect` 付き）で丸ゴシック系を採用。
- **コントラスト:** カラーパレットを**ティール／ホワイト／ウォームグレー**へ刷新（既存LPと重複しない配色）。本文・補助テキスト・リンク・休診マークすべてを **WCAG AA 以上**で設計。
- **セマンティクス / アクセシビリティ:** `header / nav / main / section / footer` を導入し `<html lang="ja">` を指定。**スキップリンク**、`aria-*` 属性、**キーボード操作対応**、`:focus-visible` の可視フォーカス、`prefers-reduced-motion` 尊重、Windowsハイコントラスト（`forced-colors`）対応。
- **プログレッシブエンハンスメント:** **JavaScript 無効でも全コンテンツが利用可能**。ナビは JS 無効時にドロワー化せず通常リストとして全項目表示。
- **フォーム:** バニラJSのクライアントサイド検証（必須・形式チェック、`aria-invalid`／`aria-live` でのエラー通知、最初の不正項目へフォーカス移動、送信成功メッセージ）。実送信は行わないデモ実装。
- **演出:** `IntersectionObserver` によるスクロール連動の段階表示と、控えめなヒーロー視差。いずれも reduced-motion 設定時は無効化。
- **SEO / SNS:** 検索意図を含む `<title>`、`meta description`、**OGP・Twitterカード**、`theme-color` を整備。
- **依存ライブラリ:** なし（HTML / CSS / バニラJSのみ）。

## 測定できる改善

数値は本サンプルの実装値・設計値に基づく例示です（実在サイトの計測値ではありません）。

| 観点 | Before | After |
|------|--------|-------|
| スマホ表示（幅320px） | 横スクロール＋ピンチズーム必須 | 横スクロールなし・等倍で判読可 |
| 本文の文字サイズ | 12px（行間1.3） | 約16〜17px（行間1.85、`clamp()`で可変） |
| 電話番号のタップ発信 | 不可（プレーンテキスト） | 可（全箇所 `tel:` リンク） |
| 本文コントラスト比（例） | 約2.8:1（淡背景＋`#999999`、AA不適合） | 約11:1（`#243B38`／`#F4F8F7`、AAA水準） |
| フッターリンク（例） | 約1.3:1（`#3e8e41`／`#1b5e20`、判読困難） | 約9:1（白88%／濃ティール背景、AA以上） |
| 休診マーク（×） | `#cc0000` ほぼ赤一色 | `#C2453B`／白で約4.7:1（AA）＋読み上げ用「休診」テキスト併記 |
| 見出し構造（SEO） | 見出しタグ・ランドマークなし | `h1`〜`h3`＋`header/nav/main/section/footer` で構造化 |
| スクリーンリーダー | 画像altなし・テーブル段組みで文脈が崩壊 | 全画像に説明alt・スキップリンク・`aria`整備で読み上げ可能 |
| 問い合わせ手段 | 電話のみ（営業時間内） | 電話＋24時間受付フォーム |
