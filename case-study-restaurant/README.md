# サイト改修 ビフォーアフター事例 ― ますだ食堂（架空）

古い実装のままになっている個人経営の飲食店のWebサイトを、**スマホ対応・メニューの読みやすさ・アクセシビリティ・予約導線**の観点からまるごと作り直すと、どこまで変わるのか。本事例では、架空の大衆食堂「ますだ食堂」を題材に、**2008年当時の作りのサイト（Before）** を、**現在の標準にあわせた新しいサイト（After）** へ改修した過程をまとめています。デザインの好みではなく、「なぜその変更が来店・予約につながるのか」を一つひとつ言語化することを重視しました。

> ⚠️ **架空サンプルについて**
> 店名・店主名・住所・電話番号・価格・メニュー・口コミなどはすべて**架空のサンプル**です。実在の飲食店・人物・団体とは一切関係ありません。地図・店内写真・料理・ヒーロー画像もSVGで作成したプレースホルダーです。

## 改修前の問題点（カテゴリ別）

改修前のサイトには、**「来店・予約の入口を細くしている要因」** が複数埋め込まれていました。それぞれ「何が問題か → なぜ集客・信頼の損失になるか」で整理します。

### 1. レスポンシブ非対応 / モバイル
- **問題:** `<meta viewport>` が無く、`width="800"` の固定幅テーブルを `<center>` で中央寄せ。
- **損失:** 「近くでお昼を食べる店」を探す人の多くはスマホ閲覧。営業時間・電話番号・メニューが指で拡大しないと読めず、面倒になった見込み客が離脱。検索流入で最も多いモバイルユーザーを取りこぼしています。

### 2. メニューが画像（飲食店サイト特有の最重要ポイント）
- **問題:** お品書きが画像1枚に文字を焼き込んだもの。`alt` も無く、価格も画像の中。
- **損失:** 価格改定や季節メニューの差し替えのたびに画像を作り直す必要があり、店主自身では更新できず何年も古いまま放置。読み上げ環境・検索エンジンには「お品書き」という文字すら届かず、「定食 ◯◯円」で探している人に見つけてもらえません。

### 3. 価格・営業時間・定休日の可読性
- **問題:** `font-size:12px` / `line-height:1.3` と極端に小さく、定休日の注記は淡背景に `#999999`。
- **損失:** 「いくらか」「いつ開いているか」は来店判断の核。読みづらさで予算が伝わらず、定休日（水・日）を見落として「行ったら閉まっていた」というトラブルや、低評価の口コミにつながります。

### 4. デザインの古さ / 第一印象
- **問題:** `<marquee>` で流れるお知らせ、`<blink>` の NEW!、偽アクセスカウンター、`Since 1998`、ベベルボタンなど 2008 年当時の演出。
- **損失:** 飲食店は「清潔感」「おいしそうか」を第一印象で判断されます。開いた瞬間に古びた印象を与えると、味や衛生面まで疑われ、きれいな競合サイトと比較されて選択肢から外されます。

### 5. 非推奨HTML / セマンティクス
- **問題:** `<font>`・`align`・`<center>`・`bgcolor` を多用。画像に `alt` なし。`header/nav/main/footer` ゼロ。`<html>` に `lang` 指定なし。
- **損失:** 画像が出ない時や読み上げ環境で内容が伝わらず、地図・料理写真が無意味に。検索エンジンも構造を理解できず、「なかまち 定食」「近くの食堂」検索で上位に出にくくなります。

### 6. 電話・予約導線 / 操作性
- **問題:** 最重要の電話番号がすべてプレーンテキストで `tel:` リンクになっておらず、スマホでタップ発信できない。予約手段は電話のみで、営業時間外は受け付けられない。
- **損失:** スマホで「今夜行こう」と思った人が番号を手入力する手間を強いられ、面倒さからそのまま離脱。営業時間外（深夜・早朝）に予約を思い立っても受け皿がなく、宴会・お持ち帰りの相談も取りこぼします。

### 7. head / SEO・SNS
- **問題:** `meta description`・OGP・Twitterカードが皆無。`<title>` が「ますだ食堂ホームページ」と弱い。`head` に `alert` を出す簡易スクリプト直書き。
- **損失:** SNSやLINEでお店のURLを共有してもリッチなプレビューが出ず、口コミ的にシェアされにくい。検索結果でも魅力的な説明文が出ずクリック率が低下し、新規来店の入口が細くなります。

## 改修内容（Before → After 対応表）

| 課題 | 改修（After で行ったこと） | 効果 |
|------|---------------------------|------|
| スマホで横スクロール必須 | `<meta viewport>` 追加＋モバイルファースト設計。固定800px幅を撤廃 | 幅320pxでも横スクロールなし。スマホでそのまま読める |
| メニューが画像で更新不能 | 画像メニューを、価格付きのHTMLメニューカードへ。説明文も付与 | 店主が自分で更新でき、読み上げ・検索・コピーにも対応 |
| 価格が画像内で不明瞭 | 各メニューに税込価格を明記。人気・名物にラベル付け | 来店前に予算がわかり、「思ったより高い」離脱を防ぐ |
| 営業時間・定休日が読めない | 曜日別の営業時間テーブル化＋定休日（水・日）を明示 | 「開いている日」を取り違えての来店トラブルを防ぐ |
| marquee/blink/偽カウンター | 静的な「お知らせ」リスト＋落ち着いた藍基調へ刷新 | 「きちんと営業している店」という第一印象 |
| `<font>`・`align`・alt無し画像 | セマンティックHTML5＋全画像に説明的`alt` | 読み上げ・SEO・画像非表示時にも内容が伝わる |
| タップ発信できない電話番号 | すべて `tel:` リンク化。タップ領域44px以上 | スマホからワンタップで予約電話。離脱を防ぐ |
| 弱いtitle・OGP無し | 検索意図を含むtitle＋description＋OGP/Twitterカード | 「近くの定食屋」検索・SNSでクリックされやすくなる |
| 予約が電話のみ | 予約・お持ち帰り・宴会に対応した24時間フォームを新設 | 営業時間外でも受付でき、予約の取りこぼしを減らす |

## 技術的な変更点

- **レイアウト:** ネストした `<table>` / `spacer.gif` / `<center>` を全廃し、**CSS Grid・Flexbox** で再構築。営業時間だけは意味的に正しい `<table>`（`<caption>`・`<thead>`・`scope`付き）として残し、狭い画面では表だけが横スクロールしてページ本体は崩れない設計に。
- **メニューの構造化:** 飲食店サイトの肝である「画像1枚のお品書き」を、**価格付きのHTMLメニューカード**（品名・税込価格・説明）へ作り替え。店主が文字を直すだけで更新でき、検索・読み上げ・コピーに対応。名物・人気にはラベルを付与。
- **レスポンシブ:** `<meta viewport>` を追加し、**モバイルファースト**で記述。幅320pxで横スクロールが出ないことを確認済み。`min-width` ブレークポイントで段階的に多カラム化。
- **タイポグラフィ:** `font-size` を `clamp()` で可変化（本文16〜17px／行間1.85）。環境依存の `ＭＳ Ｐゴシック` をやめ、Google Fonts（`preconnect` 付き）で丸ゴシック系を採用。
- **コントラスト:** カラーパレットを**藍（インディゴ）／生成り／朱／山吹**の暖色和モダン系へ刷新（既存の整骨院事例＝ティール系とは別系統）。本文・補助テキスト・リンク・定休マークすべてを **WCAG AA 以上**で設計。
- **セマンティクス / アクセシビリティ:** `header / nav / main / section / footer` を導入し `<html lang="ja">` を指定。**スキップリンク**、`aria-*` 属性、**キーボード操作対応**、`:focus-visible` の可視フォーカス、`prefers-reduced-motion` 尊重、Windowsハイコントラスト（`forced-colors`）対応。
- **プログレッシブエンハンスメント:** **JavaScript 無効でも全コンテンツが利用可能**。ナビは JS 無効時にドロワー化せず通常リストとして全項目表示。スクロール演出（reveal）も JS 無効時は最初から全表示。
- **フォーム:** バニラJSのクライアントサイド検証（必須・形式チェック、`aria-invalid`／`aria-live` でのエラー通知、最初の不正項目へフォーカス移動、送信成功メッセージ）。予約・お持ち帰り・宴会の用件、希望日・人数も選べる構成。実送信は行わないデモ実装。
- **演出:** `IntersectionObserver` によるスクロール連動の段階表示と、控えめなヒーロー視差。いずれも reduced-motion 設定時は無効化。
- **SEO / SNS:** 検索意図を含む `<title>`、`meta description`、**OGP・Twitterカード**、`theme-color` を整備。
- **依存ライブラリ:** なし（HTML / CSS / バニラJSのみ）。

## 測定できる改善

数値は本サンプルの実装値・設計値に基づく例示です（実在サイトの計測値ではありません）。

| 観点 | Before | After |
|------|--------|-------|
| スマホ表示（幅320px） | 横スクロール＋ピンチズーム必須 | 横スクロールなし・等倍で判読可 |
| メニューの更新性 | 画像のため店主が更新不能 | HTMLテキストで店主が更新可・検索/読み上げ対応 |
| 価格表示 | 画像内・変更困難で不明瞭 | 各品に税込価格を明記（来店前に把握可） |
| 本文の文字サイズ | 12px（行間1.3） | 約16〜17px（行間1.85、`clamp()`で可変） |
| 電話番号のタップ発信 | 不可（プレーンテキスト） | 可（全箇所 `tel:` リンク） |
| 本文コントラスト比（例） | 約2.8:1（淡背景＋`#999999`、AA不適合） | 約12:1（`#2A2622`／`#FAF4E8`、AAA水準） |
| 定休日（×） | `#cc0000` ほぼ赤一色・小さな注記 | `#C0392B`／白で約5.0:1（AA）＋「定休日 水・日」ラベル＋読み上げ用「定休」テキスト併記 |
| 見出し構造（SEO） | 見出しタグ・ランドマークなし | `h1`〜`h3`＋`header/nav/main/section/footer` で構造化 |
| 予約手段 | 電話のみ（営業時間内） | 電話＋24時間受付フォーム（予約／お持ち帰り／宴会） |
