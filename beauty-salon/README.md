# 月白 -Tsukishiro- アトリエ｜美容サロン ランディングページ

「肌が、静かに目を覚ます。」をコンセプトにした、架空のプライベート美容サロンのレスポンシブ LP です。
**インフォームド・ラグジュアリー志向**（静けさ・職人性・余白の美に反応する層）に向けた「売り込まない設計」を、フレームワーク不使用の手書き HTML / CSS / JavaScript で実装しています。

> ※ これはポートフォリオ用に制作した**架空のサンプル**です。掲載のブランド・住所・電話番号・お客様の声はすべてフィクションです。

## 技術

- **HTML5**：セマンティックなマークアップ。`h1` は 1 つ、見出し階層を論理的に。
- **CSS（手書き / フレームワーク不使用）**
  - `:root` のカスタムプロパティで色・余白・角丸・モーションを一元管理
  - `clamp()` による流体タイポグラフィ
  - `grid` / `flexbox` による左右非対称のモダンレイアウト
  - モバイルファースト・レスポンシブ（320px 〜 1440px+、横スクロールなし）
- **JavaScript（バニラ / ライブラリ不使用）**
  1. モバイルナビ開閉（背景クリック・Escape・リサイズで自動クローズ）
  2. FAQ アコーディオン（クリック + Enter / Space、`aria-expanded` 更新、高さアニメ）
  3. ページ内アンカーのスムーズスクロール（フォーカス移動付き）
  4. `IntersectionObserver` によるスクロール表示アニメ（下からフェードイン）
  5. 見出しの文字単位リビール（50ms ディレイ）
  6. ヒーローのパララックス（最大 40px、`requestAnimationFrame` スロットル）
  7. 申込フォームの `e.preventDefault()` バリデーション → インライン成功メッセージ（**実送信なし**）
- **フォント**：Google Fonts を `display=swap` で読み込み
  - 見出し：Shippori Mincho B1
  - 本文：Zen Kaku Gothic New
  - 英字補助：Cormorant Garamond
- **画像**：写真は [picsum.photos](https://picsum.photos) の固定 seed URL（404 を出さない安定参照）+ `loading="lazy"`。アイコン・装飾はインライン SVG / CSS グラデーションで自作。

### アクセシビリティ
- 画像 `alt`、フォーム `label` 紐付け
- ナビ / アコーディオンに `aria-expanded`・`aria-controls`
- `:focus-visible` のフォーカスリング、本文へのスキップリンク
- 文字色と背景のコントラスト AA 以上を意識した配色
- `prefers-reduced-motion` 対応（アニメーション・パララックスを無効化）

## ローカルでの開き方

外部依存（Google Fonts / picsum.photos）の読み込みにインターネット接続が必要です。

### 方法 A：ファイルを直接開く（最も簡単）
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開きます。

### 方法 B：ローカルサーバーで開く（推奨）
一部ブラウザの挙動を実環境に近づけたい場合は、簡易サーバー経由が確実です。

```powershell
# このフォルダ（beauty-salon）に移動してから実行
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

起動後、ブラウザで <http://localhost:8000> を開きます。

### 動作確認のポイント
- ブラウザ幅を 320px〜 まで狭め、横スクロールが出ないこと
- モバイル幅でハンバーガーメニューが開閉すること
- FAQ がクリック / キーボード（Enter・Space）で開閉すること
- 申込フォームを空欄送信 → エラー表示、正しく入力 → 成功メッセージが出ること
- OS の「視差効果を減らす」設定でアニメーションが無効化されること
