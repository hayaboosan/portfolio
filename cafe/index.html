WHY AKANE

茜が選ばれる理由

火と、土と、夜明けの時間。手仕事の温度を、ひとつのカップに。

0 焙煎後の提供基準
0 季節の豆ラインナップ
0 ダイレクトトレード産地

  • 焙煎は、毎朝この場所で。

    店の奥に据えた小型焙煎機で、提供する分だけを毎朝ロースト。香りが最も立つ「焙煎後48時間以内」の豆だけをカップに注ぎます。

  • 産地まで、顔の見える豆。

    エチオピア、グアテマラ、インドネシア。生産者と直接つながるダイレクトトレードの豆を、季節ごとに5〜7種類。すべて産地と農園名を明記しています。

  • 一杯ずつ、ハンドドリップ。

    注文を受けてから、一杯ずつ丁寧にハンドドリップ。豆ごとに湯温と抽出時間を変え、その豆がいちばん輝く味を引き出します。

  • 焙煎所の、焼きたて菓子。

    コーヒーに合わせて毎日焼く、自家製のスコーンとパウンドケーキ。北海道産発酵バターと国産小麦を使い、甘さは控えめに。

  • 本を読むための、静けさ。

    会話はそっと、音楽は控えめに。一人でも気兼ねなく長居できる、読書とひと息のための席を用意しています。
