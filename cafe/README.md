# 焙煎所 茜 -AKANE ROASTERY- ランディングページ

スペシャルティコーヒーの焙煎所・カフェを想定した、レスポンシブなランディングページのサンプルです。
「火・土・夜明け」をテーマに、暖色 × 明朝太め × 紙の質感で “食欲と手仕事の温度” を表現しています。

> ※これはポートフォリオ用に制作した**架空**のサンプルです。実在の店舗ではありません。

---

## 概要

| 項目 | 内容 |
| --- | --- |
| ジャンル | 飲食店・カフェ（自家焙煎コーヒースタンド） |
| ターゲット | 30〜45歳・都市部在住で「丁寧な暮らし」に価値を置く層、在宅ワーカー |
| トーン | 暖色（濃茶 × 焙煎オレンジ）／ 明朝太め見出し ／ 直線 + 紙質感 |
| 構成 | ヘッダー → ヒーロー → 特徴 → 料金プラン → お客様の声 → FAQ → 申込フォーム → フッター |

## 技術スタック

- **HTML5**（セマンティックマークアップ、`h1` は 1 つ、論理的な見出し階層）
- **CSS3**（手書き・フレームワーク不使用）
  - `:root` のカスタムプロパティで色・余白・角丸・モーションを一元管理
  - `clamp()` による流体タイポグラフィ
  - CSS Grid / Flexbox によるレスポンシブレイアウト
  - インライン SVG ノイズによるペーパーテクスチャ、CSS グラデーション装飾
- **JavaScript（バニラ / ライブラリ不使用）**
  1. ヘッダーのスクロール状態切替（透明 → ぼかし背景）
  2. モバイルナビの開閉（ハンバーガー、backdrop、Esc キー対応）
  3. FAQ アコーディオン（クリック + Enter / Space、`aria-expanded` 更新、高さアニメ）
  4. ページ内アンカーのスムーズスクロール（ヘッダー高さ補正・フォーカス移動）
  5. `IntersectionObserver` によるスクロール表示アニメ + 数字のカウントアップ
  6. 申込フォームのクライアントバリデーション → インライン成功メッセージ（実送信なし）
- **フォント**：Google Fonts（`display=swap`）
  - 見出し：Shippori Mincho B1
  - 本文：Zen Kaku Gothic New

## アクセシビリティ対応

- 内容を伝える画像には意味のある `alt` を付与。純装飾の画像は `alt=""` + `aria-hidden="true"` で支援技術から除外
- フォーム入力と `label` の `for` / `id` 紐付け、`aria-required` / `aria-invalid` / `role="alert"`
- ナビ・アコーディオンに `aria-expanded` / `aria-controls`（折りたたみ中のパネルは `hidden` 属性で支援技術・キーボードから到達不可）
- `:focus-visible` によるフォーカスリング、スキップリンク
- テキスト・主要 UI（本文／見出し／ボタン／必須バッジ／フッター小文字）の前景・背景コントラストは WCAG 2.1 AA（通常文字 4.5:1）を満たすよう調整済み
- `prefers-reduced-motion` を尊重し、全アニメーションを無効化する分岐を実装

## ローカルでの開き方

特別なビルドは不要です。インターネット接続（Google Fonts と画像 CDN の読み込み）があれば、そのまま表示できます。

### 方法 1：ファイルを直接開く
`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップしてください。

### 方法 2：ローカルサーバーで開く（推奨）
一部のブラウザ挙動を本番に近づけるため、簡易サーバーでの表示を推奨します。

```bash
# Python がある場合（このフォルダ内で実行）
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

```bash
# Node.js がある場合
npx serve .
```

> 画像は `https://picsum.photos`、フォントは Google Fonts を参照しています。
> オフライン環境では画像とフォントのみ表示されない場合があります（レイアウト・機能は動作します）。
